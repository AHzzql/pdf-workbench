# PDF 工作台手工测试样本

`workbench-test.pdf` 为 4 页普通文档，包含中英文、颜色文字、规则网格表格、一个 RGB 位图、4 个顶层书签及第一页的一个文本批注。`workbench-encrypted.pdf` 是同内容的 AES-256 加密变体；打开口令为 `open1234`，所有者口令为 `owner5678`，均仅用于合成样本。`watermark-sample.png` 为图片水印输入。

| 功能 | 操作 | 预期 |
|---|---|---|
| 文本 | 普通 PDF，页码 1 | 包含 PDFTEST-2026-A001 和中文文本 |
| 正则 | 第 1 页搜索 `alpha` | 2 处匹配 |
| 正则 | 第 1 页搜索 `CN-\d{4}-\d{3}` | 匹配 CN-2026-001 |
| 表格 | 页码 2，不限定区域 | 一张 5 行 4 列表；Total 为 45.00 |
| CSV | 导出第 2 页首张表 | 含 Notebook、Pen、Folder、Total |
| 图片 | 普通 PDF，分别导出 PNG/JPG/原始流 | 第 3 页有一个 600 x 240 位图；检查来源清单 |
| 信息 | 读取普通 PDF 信息 | 4 页、标题 PDF Workbench Functional Fixture、4 个书签、第 1 页批注 |
| 加密 | 普通 PDF 设置非空打开口令并导出 | 下载文件需要正确口令；错误口令不能读取 |
| 加密输入 | 上传加密变体并输入打开口令 | 可正常提取内容；错误或缺失口令应被拒绝 |
| 文字水印 | 第 4 页添加 TEST，坐标 60,60 | 下载件第 4 页出现水印，其他页不增加水印 |
| 图片水印 | 使用 watermark-sample.png，限定第 4 页 | 下载件第 4 页出现配套图片 |
| 无签名验证 | 验证普通 PDF | 无数字签名 |
| 数字签名 | 使用独立 PKCS#12 测试证书签署普通 PDF，再验证下载件 | 存在签名、完整性通过；证书信任单独判断 |
| 移除签名 | 对上述签署件确认移除，再验证下载件 | 无签名，普通内容和批注保留 |
| 阅读问答 | 导入文档后提问 Aurora 的预算和交付日期 | 模型服务及索引可用时，事实为 48000 元和 2026-11-15 |
| 页码校验 | 对普通 PDF 输入页码 5 | 拒绝越界页码 |
| 正则校验 | 输入非法正则 `[` | 返回参数错误 |

数字签名需要额外的 PKCS#12 证书；自签名证书的完整性有效不等于默认受信任。账户隔离、会话过期、任务恢复、服务不可用、文件大小及页数上限，需要独立环境操作或额外样本，不由该文档覆盖。当前本机配置关闭模型调用，阅读问答不具备完整运行条件。

样本结构已通过 pypdf 校验，4 页已使用 Poppler 渲染检查；这些结果不代表上述应用手工用例已执行。
