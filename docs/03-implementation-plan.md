# 实施计划

各里程碑依次执行，模块测试随实现提交。后端以 Maven 测试和构建为检查入口，前端以类型检查、组件测试和生产构建为检查入口。

| 里程碑 | 实施范围 | 验证与产出 |
| --- | --- | --- |
| M0 工程初始化 | Maven、Java 21 编译目标、启动配置、页码参数基础类 | 页码正常与非法输入测试；Spring 启动测试；mvn test、mvn package |
| M1 文本与文档信息 | PdfTextUtils、PdfInfoUtils、位置与结果模型 | 分页、中英文、样式、坐标、段落、搜索、书签、元数据、批注测试 |
| M2 简单表格 | PdfTableUtils、网格识别、CSV | 规则矩阵、空单元格、无表格、转义及错误输入 |
| M3 图片 | PdfImageUtils、资源遍历与导出 | 原始流、嵌套与内联图、重复资源、PNG/JPG、透明度及无图片 |
| M4 加密 | PdfEncryptionUtils、权限校验 | AES 128/256、正确与错误密码、独立权限位 |
| M5 数字签名 | PdfSignatureUtils、证书与验证模型 | 签署、篡改、增量修订、信任、过期、移除及独立校验 |
| M6 水印 | PdfWatermarkUtils、中文字体资源 | 文本及图片、选页、旋转、透明度、非法参数 |
| M7 API 与工作台 | Controller、Service、错误处理、OpenAPI；Vue 方案 A 页面 | 实际 HTTP 调用、Swagger、上传至下载全流程、并发与清理、前端构建 |
| M8 调用示例 | example 下独立 main 入口 | 每项静态能力脱离 Spring 执行并检查输出 |
| M9 自动化回归 | 工具、接口和浏览器测试；输出独立验证 | mvn test、mvn package、前端测试及构建；修复与复测 |
| M10 最终文档 | 校正需求与设计，形成实测报告和需求追踪表 | 原始要求逐项对应类、方法、API、示例、测试与章节 |

每个模块先建立确定性样本和预期结果，再实现入口与算法，最后运行模块测试及已有回归。构建失败按错误定位到依赖、编译或断言，修改对应范围；同一里程碑验证完成后再进入下一项。
