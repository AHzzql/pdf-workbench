# PDF 文档处理系统需求分析

## 1. 范围与依据

依据：《2026实践性作业要求.docx》。系统提供 PDF 解析、加密、数字签名和水印处理，支持独立工具调用及 HTTP 接口访问。

需求对应关系如下。

| 原始要求 | 需求 |
| --- | --- |
| 文本提取：按页面；坐标、字体、字号、颜色 | FR-01、FR-02 |
| 文本提取：正则搜索；按顺序抽取段落 | FR-03、FR-04 |
| 文本提取：书签；作者、标题、自定义元数据；高亮、备注 | FR-05、FR-06、FR-07 |
| 表格提取：简单交叉表、单元格文本 | FR-08 |
| 图片提取：所有图片二进制流、PNG/JPG | FR-09 |
| PDF 加密：两类密码、打印/复制/修改权限、128/256 位 | FR-10 |
| 数字签名：证书签名、验签、移除签名、有效性 | FR-11、FR-12、FR-13 |
| 文档水印：文本与图片 | FR-14、FR-15 |
| Java/Spring Boot、JDK 21 以上、静态工具、调用例子、Swagger、开发与文档 | 第 3 节 |

Vue 工作台提供文件选择、参数输入、预览、结果显示和下载。系统范围不包含账户、数据库、OCR、复杂表格及长期文件存储。

## 2. 功能需求

### FR-01 分页文本提取

- 来源：文本提取“按页面提取文本”。
- 功能与输入：输入 PDF、可选打开密码和页码范围，提取指定页的可编码文字；未指定范围时处理全部页面。
- 输出与正常情况：按原页码返回每页文本，页码从 1 开始，不混合不同页面；空白页保留页记录和空文本。
- 主要异常：页码超出文档范围、文件损坏、密码错误、缺少提取权限。纯扫描件返回空文本。
- 验收：单页、多页、中文样本与已知文字逐页比对；选择第 2 页不包含第 1 页正文；空白页不报解析失败。

### FR-02 文本位置与样式

- 来源：文本提取“文本块坐标、字体、字号、颜色”。
- 功能与输入：输入 PDF 和指定页，返回文本块的位置和样式；块内样式变化需保留为独立片段。
- 输出与正常情况：文字、所属页、矩形、字体名称、字号、颜色及坐标含义；不同字号或颜色不得合并后丢失信息。
- 主要异常：缺少字符映射、无法还原的颜色或字体信息需明确说明，未知字段返回空值。
- 验收：带已知坐标、两种字号和颜色的样本逐项比对；另测裁剪页和旋转页，矩形与显示位置相符。字号容差 0.1 pt、普通横排边界位置容差 1 pt，通过已知参数样本进行数值检查。

### FR-03 段落顺序

- 来源：文本提取“按顺序抽取段落内容”。
- 功能与输入：输入含文本的 PDF 页面，形成可读的段落序列。
- 输出与正常情况：每页的有序段落及其文本块关系；支持普通横排单栏与规则双栏，保留段落分隔，不将双栏逐行交错。
- 主要异常：复杂浮动排版或无法可靠区分阅读顺序时给出限制说明，保留可提取文本及位置。
- 验收：内容写入顺序与视觉顺序不同的样本仍按既定阅读顺序输出；单栏和双栏分别与人工标注序列比对。段落识别范围限于普通横排单栏与规则双栏。

### FR-04 正则搜索

- 来源：文本提取“正则搜索文本”。
- 功能与输入：输入 PDF、页码范围、正则表达式，按页搜索提取文本。
- 输出与正常情况：命中文字、页码、匹配范围及对应文本位置；无匹配返回空列表，跨行匹配遵循文档说明的文本和换行规则，不跨页拼接。
- 主要异常：空表达式、非法或不支持的正则语法应返回明确错误，不把异常当作无命中。
- 验收：普通、中文、多次、跨行匹配及无命中结果准确；非法模式可恢复；正则支持范围在接口中说明。

### FR-05 书签提取

- 来源：文本提取“提取书签”。
- 功能与输入：输入具有目录书签的 PDF，读取层级和跳转目标。
- 输出与正常情况：书签标题、子书签及可解析的目标页；不含书签时返回空列表。
- 主要异常：无效目标的页码返回空值；外部链接只返回信息，不访问链接；循环引用不导致无限处理。
- 验收：两级书签的顺序、父子关系和目标页与样本一致；无书签和无效目标均可处理。

### FR-06 元数据提取

- 来源：文本提取“元数据（作者、标题、自定义元数据）”。
- 功能与输入：读取 PDF 的标准信息和自定义信息。
- 输出与正常情况：至少包含作者、标题以及全部自定义键值；存在 XMP 时单独保留其内容或可解析字段，避免覆盖同名但来源不同的数据。
- 主要异常：缺失字段返回空值；损坏的可选元数据给出诊断，不导致已可读取正文丢失。
- 验收：中文作者、标题、自定义键值准确；缺失信息返回空值。

### FR-07 注释与批注提取

- 来源：文本提取“注释批注（高亮、备注）”。
- 功能与输入：读取每页的注释，重点支持高亮与文本备注。
- 输出与正常情况：页码、类型、作者、内容和位置；高亮保留其多个标记区域，备注内容可为空。
- 主要异常：无法解释的注释类型保留类型与可读取内容；异常坐标给出诊断。
- 验收：含高亮、多行高亮和备注的样本中，数量、文字及位置正确；无注释返回空列表。

### FR-08 简单表格提取

- 来源：表格提取“简单交叉表”“获取单元格文本”。
- 功能与输入：输入具有水平、垂直边框的简单规则表格 PDF，可指定页码或矩形区域。
- 输出与正常情况：每张表的页码、边界以及按行列组织的单元格文本；空单元格保留位置，多行内容仍属于原单元格。
- 主要异常：无表格返回空列表；复杂合并单元格、无边框推断、嵌套表及跨页拼接不在范围内。
- 验收：已知 4×3 表格完整还原，含中文和空单元格；无表格页没有误报。CSV 下载属于结果呈现方式，不扩大表格识别范围。

### FR-09 图片提取与保存

- 来源：图片提取“所有图片二进制流”“保存 PNG/JPG”。
- 功能与输入：读取 PDF 中的图片数据，支持直接图片资源、嵌套资源及内容流内联图片；可选择 PNG 或 JPG 导出。
- 输出与正常情况：原始编码数据及可解码导出文件、尺寸、类型和来源记录；同一图片重复引用可以去重，但不得丢失出现位置或引用关系；不以整页截图代替图片提取。
- 主要异常：单个图片无法解码时记录原因并保留能读取的原始数据；无图片返回空结果。JPG 不支持透明度，导出时明确采用白色背景。
- 验收：单图片、多图片、透明图、重复引用、嵌套和内联样本逐项核对数量与像素；原始流与源对象字节比较；无图片结果为空。未被绘制但可达的图片资源亦应检查。

### FR-10 加密与权限

- 来源：PDF 加密整条要求。
- 功能与输入：输入 PDF、现有打开密码（如需）、新用户密码、新所有者密码、128/256 位选择及打印/复制/修改权限。
- 输出与正常情况：输出新加密 PDF；用户密码用于打开文件，所有者密码用于管理权限；三个权限分别生效。原文件不变。
- 主要异常：错误的原密码、不支持的密钥长度、空所有者密码或两类新密码相同需拒绝；已有签名文档不静默改写。
- 验收：128 位和 256 位分别验证实际加密参数、正确/错误密码及权限位；用用户密码进行禁止的操作被本系统拒绝。权限控制依赖阅读器执行 PDF 权限规则。

### FR-11 证书签名

- 来源：数字签名“PDF 签名”“支持证书签名”。
- 功能与输入：输入 PDF、包含私钥和证书链的 P12/PFX、容器密码，以及可选签名原因和地点。
- 输出与正常情况：输出含证书数字签名的新 PDF，不改变已有正文；签名图案不作为数字签名替代物。
- 主要异常：证书密码错误、无私钥、条目不明确、算法不支持、证书不在有效期或文档不允许签署需明确拒绝。
- 验收：测试证书成功签署并通过独立校验，签后正文及页数不变；无效证书不生成输出文件。初始实现支持 RSA/SHA-256，不包含时间戳服务和可见签章业务。

### FR-12 验签与有效性判断

- 来源：数字签名“验签”“校验签名有效性”。
- 功能与输入：输入 PDF，可选提供受信任根证书，逐项验证已有签名。
- 输出与正常情况：分别给出签名字节完整性、签后是否存在追加修订、证书当前有效期和证书链信任结论；未提供信任根为未评估，不等同于可信或不可信。
- 主要异常：签名损坏属于验证结果；文档不可解析才属于处理失败；无签名返回空列表。
- 验收：正常签名、被修改字节、合法增量修改、过期证书和未提供根证书分别有正确结论。吊销检查及可信时间戳验证不在范围内。

### FR-13 移除签名

- 来源：数字签名“移除签名”。
- 功能与输入：输入已签名 PDF，生成移除全部数字签名的新文件。
- 输出与正常情况：新文件中不保留签名字段、其控件及签名关联；正文、非签名表单和普通注释保留，原文件不变。
- 主要异常：受权限保护或不能安全处理的结构明确报错；无签名文件返回不含签名的有效副本，移除数量为 0。
- 验收：重新打开文件后签名数量为 0，正文及普通表单内容一致；新文件不再具有原签名认证效力。

### FR-14 文本水印

- 来源：文档水印“文本”。
- 功能与输入：输入 PDF、文本、目标页以及字号、颜色、位置、角度和透明度。
- 输出与正常情况：输出新增水印的 PDF，支持中文，不覆盖源文件，不改变原有正文的可提取性。
- 主要异常：空文本、非法页码、越界参数、字体缺字和已签名文档不能被静默接受。
- 验收：指定页出现正确文字，未选页不变；中文无方框，位置、方向与透明度符合参数。

### FR-15 图片水印

- 来源：文档水印“图片”。
- 功能与输入：输入 PDF、PNG/JPG 水印图片、目标页、位置、尺寸、角度和透明度。
- 输出与正常情况：输出含图片水印的新 PDF，等比缩放，PNG 透明区域保留。
- 主要异常：损坏或不支持的图片、非法尺寸或透明度需拒绝；不将任意文件当作图片解码。
- 验收：PNG、JPG 两种输入有效；比例、位置和透明度可验证；选页以外内容不变。

## 3. 工程与交付要求

| 要求 | 验收方式 |
| --- | --- |
| Java 或 Spring Boot；JDK 21 及以上 | 检查项目编译配置与实际 Java/Maven 输出，通过 IDEA 启动后端 |
| 工具类、静态方法 | 每个核心工具类为 final、私有构造器、public static 入口；工具层不依赖 Spring、HTTP 或 MultipartFile |
| 调用例子 | 每项能力有可运行示例，直接调用工具方法，不启动 Spring；示例使用可取得的测试文件，不依赖个人绝对路径 |
| Swagger 生成 API 说明 | OpenAPI 文档与实际请求字段、响应一致，页面可访问，各能力可通过接口实际调用 |
| 源代码及三类文档 | 交付源代码、需求分析说明书、软件设计说明书和软件测试报告 |

公共 API 提供 Javadoc。PDF 文档和流在操作结束后关闭；异常保留原因，日志排除密码、私钥及正文。各功能均验证输入校验、临时文件清理和输出文件有效性。

## 4. 验收安排

每个 public static 核心入口至少验证正常、边界和非法输入；具体样本及方法见设计中的测试章节。最终执行 `mvn test`、`mvn package`，另验证真实 HTTP 请求、Swagger 页面、Vue 构建和工作台操作。验收记录包括构建输出、测试结果、接口响应及输出文件内容校验。

最终逐项建立“原始要求 → 实现类及静态方法 → API → 调用示例 → 测试 → 文档章节”的对应关系。
